# Syntactic Analyzer

## ▶️ Running the Analyzer

To execute the syntactic analyzer, run the following command from the root directory:

```bash
python3 -m syntactic_analyzer.test_syntactic test_cases/test_case1.pas
```

Additional test cases are provided in the `test` directory (e.g., `test_case2`, `error_case1`).
You can also provide your own Pascal source file as input to analyze different programs.
